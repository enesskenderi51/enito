# English C1 Projekt

Projekt zum Erreichen bzw. Trainieren von Englisch auf Niveau C1.

## Struktur
* `tickets/`  Ein Ticket pro Aenderung
* `prompts/`  Der Umsetzungsprompt zu jedem Ticket
* `reports/`  Der Report nach jeder Umsetzung
* `src/`      Quellcode
* `tests/`    Tiering Test Strategie (Tier 1 Unit, Tier 2 Integration, Tier 3 E2E)

Die Arbeitsregeln stehen in der `CLAUDE.md` im Wurzelverzeichnis.
