## Ziel
Den manuellen Prüfworkflow des Lernportals in drei automatisierte Test Tiers überführen, damit jede Änderung in Sekunden abgesichert ist und kein Tier einen schnelleren blockiert.

## Kontext

* Kein Build, keine Abhängigkeiten in der HTML Datei

## Arbeitsregeln
Es gelten R1 bis R8 aus `prompts/META_PROMPT.md`. Besonders wichtig: R6 (Tier 1 muss in Sekunden laufen, keine externen Pakete) und R5 (ein kleiner Loader als Modul, Tests als reine Funktionen).

## Phase 1: Erkunden
* Wie sind die Pools deklariert (`const` auf oberster Ebene), welche Browser APIs werden beim Laden des Scripts angefasst?
* Welche Funktionen sind rein und ohne DOM testbar?
* Noch kein Code

## Phase 2: Planen
* **Loader** (`tests/lib/portal.js`): Scriptblock per Regex extrahieren, in einem `node:vm` Kontext ausführen. DOM und Browser APIs werden durch einen rekursiven Proxy ersetzt (Null Object Muster), damit Top Level Code ohne jsdom läuft. Top Level `const` eines Scripts ist in späteren `runInContext` Aufrufen desselben Kontexts sichtbar, darum Zugriff über `portal.get('grammarPool')`. Laden O(n) in der Dateigrösse, einmal pro Testprozess gecacht. Verworfen: jsdom (externe Abhängigkeit, Faktor 50 langsamer) und Regex Extraktion einzelner Arrays mit eval (fragil bei Kommentaren und Strings).
* **Zustand**: keiner. Der Loader liefert einen frischen, isolierten Kontext, `window.storage` ist ein In Memory Stub.
* **Entwurfsmuster**: Null Object (Proxy) für die Browser Umgebung, Facade für den Zugriff auf den Kontext. Mehr ist nicht nötig.
* **Schnittstellen**: `loadPortal() -> {get(name), run(code)}`, `extractScript(html)`, `panelDivBalance(html, id)`

## Phase 3: Umsetzen
1. Loader schreiben | Test zuerst: Pools laden, Längen > 0, Tier 1 | fertig wenn: lädt unter 1 Sekunde
2. Tier 1 Tests: Syntax (`node --check` auf extrahiertes Script), div Bilanz aller acht Panels, `qid` deterministisch, `weightOf` = max(0.002, 0.65^m), `varyText` lässt Antwortoptionen unberührt, `classifyTopic` liefert gültigen Themenindex | fertig wenn: grün unter 5 Sekunden
3. Tier 2 Tests: Datenintegrität aller Pools wie im Ticket | fertig wenn: grün, Befunde im Ist Zustand werden dokumentiert statt versteckt
4. Tier 3 Test: Playwright, Datei per `file://` öffnen, acht Tabs anklicken, `pageerror` sammeln | fertig wenn: grün
5. `package.json` mit Skripten `test`, `test:t1`, `test:t2`, `test:t3`
