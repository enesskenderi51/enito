# T-0001: Testfundament nach Tiering Strategie für das Lernportal

**Status:** erledigt
**Datum:** 22.11.2026

## Ziel
Der manuelle Prüfworkflow aus `english-c1/CLAUDE.md` (node --check, Smoke Test, div Bilanz) wird automatisiert und auf drei Tiers verteilt. Jede spätere Änderung (zuerst Speaking, T-0002) bekommt damit eine schnelle Feedbackschleife, ohne dass Tests zum Flaschenhals werden.

## Akzeptanzkriterien
* [x] Ein Befehl pro Tier: `npm run test:t1`, `npm run test:t2`, `npm run test:t3`, dazu `npm test` für Tier 1 und 2
* [x] Keine externen Abhängigkeiten für Tier 1 und 2 (nur Node Bordmittel, `node:test`, `node:vm`)
* [x] Tier 1 unter 5 Sekunden: Syntax des Scriptblocks, div Bilanz aller acht Panels, reine Funktionen (`qid`, `weightOf`, `varyText`, `classifyTopic`)
* [x] Tier 2 unter 30 Sekunden: Datenintegrität aller Pools (genau 3 Optionen, gültiger Lösungsindex, keine doppelten Optionen, Titelformat der Reading Tests, genau 10 eindeutige Wörter pro Wortkasten, Karteikarten vollständig, Mengen laut CLAUDE.md als Untergrenze)
* [x] Tier 3: Playwright Smoke Test mit dem vorinstallierten Chromium, alle acht Tabs öffnen ohne JavaScript Fehler
* [x] Bestehendes Verhalten der HTML Datei bleibt unverändert

## Betroffene Bereiche
* neu: `english-c1/package.json`, `english-c1/tests/**`
* unverändert: `english-c1/src/aptis-c1-lernportal.html`

## Test Tier
* Tier 1: Syntax, div Bilanz, reine Funktionen
* Tier 2: Datenintegrität
* Tier 3: Browser Smoke Test
