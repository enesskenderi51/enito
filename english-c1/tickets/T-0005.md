# T-0005: Reading Task 3 und 4 im offiziellen Phrasenformat

**Status:** erledigt
**Datum:** 22.11.2026

## Ziel
In Aptis Advanced sind die Lücken in Task 3 und 4 Phrasen, nicht Einzelwörter. Bisher hat nur Test I dieses Format. Entscheid von Enes: Originale behalten, ergänzen. Die bestehenden Task 3 und 4 in A bis H bleiben als Einzelübung, für den kompletten Test kommen pro Test neue Tasks im Phrasenformat dazu.

## Akzeptanzkriterien
* [x] Pro Test A bis H ein neuer Task 3 (ein Text, 5 Lücken) und ein neuer Task 4 (zwei Texte, 6 Lücken), Optionen als Phrasen
* [x] Bisherige Task 3 und 4 von A bis H tragen `practice: true` und bleiben in der Einzelübung
* [x] `readingfull` nutzt pro Test genau einen Task 1, 2, 3 und 4, nie eine Übungsvariante
* [x] Lösungsposition variiert (nicht immer Option 1)
* [x] Titelformat bleibt bindend, neue Inhalte sind als selbst erstellt gekennzeichnet
* [x] Bestehende Fragen und ihr Lernstand bleiben unverändert

## Betroffene Bereiche
* `src/aptis-c1-lernportal.html`: `readingTexts`, `buildFullReading`
* `tests/**`

## Test Tier
* Tier 1: `buildFullReading` liefert nie Übungsvarianten und immer alle vier Tasks
* Tier 2: Struktur pro Test, Phrasenformat, Lückennummern im Text, Lösungsverteilung
* Tier 3: kompletter Reading Test startet ohne Fehler
